# JALWE evidence memory and language-model reasoning

`/brain` shows saved experience availability. `/brain SYMBOL` displays the existing Gemini review of the same frozen evidence: agreement/disagreement, continuation/false-breakout/exhaustion scenarios, missing evidence and the model's next observation. `/ai_system` includes memory availability. A rule-only or unsampled decision is never labelled a language-model review. Confidence percentages are not invented; probabilities remain uncalibrated.

This extends the existing reviewer rather than adding another model or experiment. The three perspectives are one model's views, not independent agents. The fixed prompt now asks it to challenge a setup using its supplied saved experience as well as current price/volume/risk evidence, and identify falsifying observations. Numeric scores, counts and text are not proof of an edge. No verified news input exists; catalyst assessment must remain UNKNOWN.

In the separate research child, at most hourly, the existing read-only native audit supplies up to 20 recent closed trades. Only consistent complete ledgers without audit findings qualify. Duplicate identities, open positions and future closes are excluded. Older missing broker execution snapshots remain explicit; PnL is saved-ledger PnL before unavailable fees. Naive native database timestamps follow the existing SQLite UTC storage convention. Truncation is disclosed. No historical jump studies or simulated profits enter this native-trade memory.

After the native execution path has finished, the watcher reads the cached memory only (no full audit or model call). It freezes counts, memory hash, exact decision timestamp/symbol/strategy and known evidence limitations at the top level of the existing decision payload, before saving it. This avoids changing the native decision fingerprint/deduplication and never influences an order. Unavailable, stale (>24h), future or invalid memory stays unknown rather than zero. The matching review uses that frozen context, never a later ledger reread. An equal numeric context from another decision has a different context identity.

Only bounded numeric all-trade and same-strategy counts reach Gemini; individual trade IDs, arbitrary metadata, secrets and error text are not forwarded. Existing exact request-body capture, prompt fingerprint, cache validity, structured response checks and reference validation remain in force. The prompt fingerprint changes, so older prompt caches are not silently treated as new reviews. Memory references are permitted for risk/scenario reasoning, never as verified news.

Gemini's existing asynchronous queue, approved free model, three-per-day configuration, sampling windows, failure accounting and no paid fallback remain unchanged. No additional provider call or external message is triggered by a command or a test. PAPER gates, risk, stop/target rules, LIVE configuration and order authority are unchanged. These are post-decision reviews, not pre-entry approvals, independent forward predictions, automatic learning or proven profitable decisions.
