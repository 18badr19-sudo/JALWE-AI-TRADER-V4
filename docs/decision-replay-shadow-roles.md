# Decision evidence and separate SMA research

`/explain SNAP` (alias `/why SNAP`) reads the last native saved decision. It shows only recorded reasons and failed gates, distinguishing broker submission from fills. Realized exit events are joined only by that decision's managed trade ID and symbol, never by symbol alone. Recorded exit action is evidence, not a claim explaining the market move. No extra LLM call or trading authority is involved.

`/replay_status` and `/replay SNAP` display the newest saved replay. Future PAPER decisions can record bounded stage inputs, responses and mutations, frozen settings, source hashes, clock reads and breakout latch state. A background audit executes the same central DecisionEngine coordinator using those recorded stage responses. Component model internals, broker fills, exits and profitability are not recomputed. Old decisions without transcripts cannot be fabricated. Replay refuses source/version mismatch and any unrecorded dependency call. Source text is archived for review, not executed. No pickle or arbitrary class imports. Disabled when LIVE is allowed or PAPER is false; `JALWE_DECISION_REPLAY_ENABLED=false` bypasses capture.

Capture has a 75ms serialization budget, 2MB raw/256KB compressed caps, a queue of 16, and 80 ordinary plus 20 ready captures per New York date. Retention is 14 days. Oversized, exceptional or unsupported captures are skipped without changing the original result. Transcript ID links to the native saved execution payload. A MATCH means central control-flow consistency under recorded responses, not proof that an entry was wise.

Gemini's existing SHADOW_ONLY request now asks for NEWS_CATALYST, MOMENTUM_LIQUIDITY and RISK_REVIEW perspectives in one response. These are three views from one model, not independent experts. Current numeric evidence contains no verified articles, so news catalyst must remain UNKNOWN. No new trading authority, paid-provider fallback, model change or daily-limit increase. `/ai_status` and `/ai_review SNAP` show the saved analysis.

Archive the exact credential-free provider request body, prompt/schema fingerprint and raw response text (including malformed completed JSON). Cache reuse requires exact provider/model/prompt/evidence identity and a currently valid structured response. It consumes no extra call or daily slot. Pending older prompt versions are marked PROMPT_CHANGED; malformed or failed cached records are not retried automatically.

`/sma_study` displays a fixed SPY daily SMA20/SMA50 long/cash study. The independent research worker reads up to 252 completed provider sessions plus warmup in the same bounded window (first 51 sessions precede the test). Requires unique valid OHLCV for every calendar session; missing/invalid days stay unknown. Signals use only closed daily bars; a fresh crossing executes at the next session's open, never that signal day's price. Whole synthetic $100 allocation, fractional units, no leverage, shorts or stop. Assumed 10/25 basis points per side. Exit is the opposite crossing. Open positions remain marked separately from closed-trade PnL; no forced last-close fill. Buy/hold uses the same test start and end and corresponding entry cost. Both ending values mark remaining holdings without hypothetical liquidation costs. Split-adjusted data exclude cash dividends; not total-return evidence. Drawdown uses daily closes and can miss intraday drawdown.

One SPY read and calendar read daily; failed reads back off one hour. No same-period strategy tuning, promotion, changes to native gates/risk/targets, or actual broker orders. Result is a retrospective single-symbol comparison, not statistical proof of superiority or realized profit.
